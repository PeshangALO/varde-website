## Varde Tech nettside med blogg

Blogg bilder blir skaler til være 400x250px, de bør redigeres til å være 800x500px før det lastes opp for å unngå artifakter.
link til gratis adobe verktøy: https://www.adobe.com/express/feature/image/resize som kan brukes til å redigere størrelsen.
1. last opp bilde.
2. trykk på låsen mellom høyde og bredde for å åpne proporsjon.
3. velg width 800 og height 500.
4. Zoom inn og ut for å justere bildet.
5. trykk på download for å laste ned bildet.
